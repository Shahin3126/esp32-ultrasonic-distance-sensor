### **ESP32 Ultrasonic Distance Sensor**



###### A beginner-friendly project using an "ESP32" microcontroller and an "HC-SR04 ultrasonic sensor" to measure distance in centimeters.



#### **Wiring Configuration**

###### 

###### | HC-SR04 Pin | ESP32 Pin | Description |

###### | :--- | :--- | :--- |

###### | \*\*VCC\*\* | \*\*V5 (VIN)\*\* | 5V Power Supply |

###### | \*\*Trig\*\* | \*\*G26\*\* | Trigger Pin |

###### | \*\*Echo\*\* | \*\*G27\*\* | Echo Pin |

###### | \*\*GND\*\* | \*\*GND\*\* | Ground |



#### **Hardware Requirements**

* ###### ESP32 Development Board
* ###### HC-SR04 Ultrasonic Sensor
* ###### &#x20;Breadboard and Jumper Wires
* ###### Micro-USB cable
